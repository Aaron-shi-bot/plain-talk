# 说清楚 · plain-talk

让 AI 用更少的绕弯，把事情讲清楚。

「说清楚」是一个中文沟通技能，适用于需求复述、知识科普、方案讨论和项目对接。它让表达更直白、顺口，同时保留真正的目的、关键条件、例外，以及它们之间的逻辑关系。

精炼不等于把所有回答压成一句话。简单问题直接答，复杂问题保留必要的解释；口语感来自好懂的讲法，不靠口头禅或过于随意的词。

## 它会怎样说话

以下是表达示例，不代表实际项目进展或运行结果。

### 需求复述

**原始描述：**

> 我想做一个客户资料整理工具，主要是方便同事快速查到信息。先支持手动录入和搜索就行，导入旧表格以后再做。没有权限的人不能看到手机号，主管可以看，但修改记录得留下来。

**使用「说清楚」：**

> 你想让同事更快查到客户资料，第一版先做手动录入和搜索，旧表格导入留到以后；手机号按权限查看，主管可以看，修改记录也要保留。

### 知识科普

**问题：** 缓存是什么，为什么会出现旧数据？

**使用「说清楚」：**

> 缓存就是把查过的数据暂时留一份，下次需要时直接拿来用，省去重新读取或计算的时间。如果原始数据变了，缓存里的那份还没更新，你看到的就可能是旧数据。所以需要根据数据的变化方式，决定什么时候更新或清掉缓存。

### 项目沟通

**已知情况：** 登录页面和接口已完成，正常登录已测通；密码错误、账号停用和弱网情况还没测试；明天演示以这些测试通过为前提。

**使用「说清楚」：**

> 登录页面和接口已经做好，正常登录也测通了。密码输错、账号停用和网络差时会怎样，还没测。如果这些测试都通过，就按计划明天演示。

## 安装到 Codex

在 Codex 中发送：

```text
请使用 skill-installer，从 https://github.com/Aaron-shi-bot/plain-talk 安装仓库根目录的技能，安装名称为 plain-talk。如果已经安装，先说明差异，不要直接覆盖。
```

也可以手动把本仓库下载后，将文件夹命名为 `plain-talk`，放进 Codex 的技能目录：默认是 `~/.codex/skills/plain-talk/`；如果设置过 `CODEX_HOME`，则放进其下的 `skills/plain-talk/`。

确认 `SKILL.md` 位于这个文件夹的第一层，`agents/openai.yaml` 和 `THIRD_PARTY_NOTICES.txt` 一并保留。安装后，在后续对话中检查是否能找到该技能。

## 使用

可以直接调用：

```text
$plain-talk 用白话解释这段内容，保留关键条件和逻辑关系。
```

也可以说“讲清楚一点”“太绕了，抓重点”或“精炼，但别丢信息”。是否自动选用技能取决于使用它的客户端及其设置。

## 让以后对话默认使用

如果希望每次都使用，在自己的 Codex 全局 `AGENTS.md` 中追加下面这段，并把路径换成实际安装位置。保留文件里原有的其他规则。

```markdown
## 默认表达方式：说清楚

每次对话读取并应用已安装的 plain-talk/SKILL.md，无需我手动调用。
默认用直白、顺口、有分寸的中文，保留真正目的、关键信息、条件、例外和逻辑关系。
复杂问题按需要展开，不刻意加口头禅，也不强求一句话。
我当次指定的语言、风格、格式和详略优先；专业任务仍保留必要的研究、验证和引用。
```

Codex 的全局指令默认在 `~/.codex/AGENTS.md`，也可能由 `CODEX_HOME` 指向其他位置。新会话会读取适用的指令；已经打开的会话是否刷新，以客户端实际加载情况为准。详见 [Codex 官方 AGENTS.md 说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

技能文件本身不会修改全局配置、写入个人记忆或替其他会话发送消息。
